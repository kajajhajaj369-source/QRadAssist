# Project boundaries

This project is a research-oriented AI medical decision-support prototype.

It will **not** claim:

- to replace radiologists
- to provide definitive clinical diagnoses
- to guarantee clinical accuracy
- to demonstrate quantum advantage without experimental evidence
- that an XAI heatmap proves disease
- that the LLM independently diagnoses an X-ray

Training and evaluation will use real-world medical imaging datasets.
AI-generated X-rays are not part of the core dataset.
