# Research questions

Working questions for the project. They are not claims of results.

**RQ1.** How effectively can a deep-learning model perform multi-label
classification of selected chest X-ray abnormalities?

**RQ2.** Can XAI techniques provide interpretable visual evidence for the
model's predictions?

**RQ3.** How does a hybrid quantum-classical classifier compare with a
classical classifier for the selected chest X-ray classification task?

**RQ4.** Can structured model predictions and explainability information be
converted into a useful natural-language report while minimizing unsupported
content?
